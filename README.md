# Modal Wan Video Lab

An experimental GPU environment for exploring open-source generative video models using Modal and Python.

## Project Goals

- Explore cloud GPU computing with Modal.
- Prepare an environment for open-source video generation models.
- Experiment with model inference and Python workflows.
- Evaluate GPU resources for generative AI workloads.

## Planned Models

- Wan video generation models.
- LTX video generation models.
- Other open-source generative video models.

## Initial Experiment

The first stage is a GPU environment verification script that checks CUDA availability and reports GPU information.

## Project Status

Currently in the initial setup and GPU testing phase.

## Planned Development

- GPU environment verification.
- Model dependency setup.
- Video inference experiments.
- Workflow optimization.

## Disclaimer

This is an independent learning and experimentation project. Model inference experiments will be conducted as GPU resources become available.
